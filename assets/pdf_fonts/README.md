# Maintainiac PDF Font Assets

These fonts are bundled so generated PDFs render deterministically offline
instead of falling back to default Helvetica behavior.

- `roboto_regular.ttf`: Roboto Regular
- `roboto_bold.ttf`: Roboto Bold

Roboto is distributed by Google under the Apache License 2.0. Keep these assets
scoped to PDF generation and QA fixtures unless the app adopts a broader font
asset policy.
