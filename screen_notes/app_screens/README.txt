Maintainiac exact screen notes

Purpose:
This folder mirrors the current Dart screen files under lib/screens so every
actual screen can collect recovered user requirements.

Important:
These files are not implementation specs by themselves. They are a durable
capture area for user-stated requirements from long conversations.

Batch 1 status:
Only requirements recovered from Batch 1 are included. Screens not mentioned in
Batch 1 are explicitly marked as having no recovered Batch 1 notes yet.
