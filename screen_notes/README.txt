Maintainiac screen/module notes

Purpose:
These files capture user-stated requirements for each major screen/module so
they do not get lost during long conversations, context compression, or future
implementation passes.

Rule:
If a new requirement is stated for a screen/module, append it to that module's
TXT file with a source/date label. Do not invent missing requirements.

Capture app requirements, feature behavior, workflows, fields, permissions,
security/data rules, and UI/UX decisions. Do not capture unrelated personal
rambling, repeated venting with no new app requirement, or invented Codex
assumptions.

See also:
docs/screen_notes_usage.md
